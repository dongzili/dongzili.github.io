This version is optimized for faster loading and easier maintenance.

Key changes:
- Removed the unused HTML5 UP template assets, jQuery, and extra pages.
- Consolidated styling into a single file: assets/site.css.
- Kept the same content and overall visual structure.
- Reduced the size of large photographs for web display.
- Added native smooth scrolling and lazy loading for non-critical images.

How to maintain:
- Edit text in index.html.
- Adjust colors, spacing, and layout in assets/site.css.
- Replace images in images/ while keeping the same filenames, or update the paths in index.html.
